# Koul

Koul lets you write trading rules for your own Stellar wallet. A Soroban contract stores the rules, checks them and runs
the trade from your passkey smart account, under a key that a policy contract limits. You keep your funds, and an
off-chain keeper only submits ticks.

- Live on Stellar testnet: https://app.koul.me
- Code (MIT): https://github.com/koul-me/koul
- Keeper status: https://koul.me/status

Read the [Architecture](architecture.md) page for how Koul works today and the plan for mainnet.
